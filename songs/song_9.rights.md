                  歸る／波浮の港にヤ 夕燒け小燒け／明日の日和は／ヤレ ホンニサ
                  凪るやら／二 船もせかれりや 出船の仕度／島の娘達ヤ 御陣家暮し／
                  なじよな心で／ヤレ ホンニサ ゐるのやら」; in the NDL copy verses
                  三–五 are written in BY HAND in the margin (a reader's
                  addition, matching the later five-verse text). So verses 3–5
                  are not in the 1924 book; the earliest print of the
                  five-verse text (the version of the 1928 Victor records) has
                  not been located. Differences 1924 print → file (verses 1–2):
                  鳥ヤ → 鳥ゃ; 日暮れに歸る → 日暮れにゃかえる; 港にヤ → 港にゃ;
                  夕燒け小燒け → 夕やけ小やけ; 明日の日和は → あすのひよりは;
                  凪るやら → なぎるやら; せかれりや → せかれりゃ; 仕度 → したく;
                  娘達ヤ → 娘たちゃ; 御陣家暮し (ruby ごじんかぐらし) → 御神火ぐらし;
                  なじよな → なじょな; ゐるのやら → いるのやら. The file is
                  therefore a modernised rendering, not a verbatim print.
